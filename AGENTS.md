# SGU J2EE Lab - AI Agent Guidelines

## 📋 General Rules for this Workspace

1. **Learning Notes Rule:**
   - Mỗi khi người dùng hỏi giải thích về code, cơ chế hoạt động (Spring IoC, DI, Annotations, Stream API, Exception, JPA,...) hoặc giải thích lỗi, trợ lý AI phải tự động tổng hợp và ghi chép kiến thức đó vào file `NOTE.md` nằm trong thư mục của bài tập tương ứng (ví dụ: `Chuong1/Phan1/BaiMau/Bai2/NOTE.md`).
   - Tham khảo chi tiết tại: [`.agents/rules/note-taking.md`](file:///.agents/rules/note-taking.md).

2. **Code Modification Constraint:**
   - Chỉ giải thích hoặc sửa đúng phạm vi người dùng yêu cầu.
   - Không tự ý sinh thêm implementation vào file code `.java` nếu người dùng chưa yêu cầu, để người dùng tự tay thực hành gõ code theo tài liệu.
